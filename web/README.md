# MistRelay Web 管理端

基于 Vue 3 + TypeScript + Vite + Tailwind CSS + Element Plus 构建的 MistRelay 现代化管理中台。采用“樱花粉 + 天空蓝”二次元流光与晶莹毛玻璃设计系统，提供集下载控制、Telegram 云盘资产管理、多机器人集群自动化治理与存储生命周期管理于一体的高品质管理体验。

---

## 核心特性与功能模块

### 1. 系统监控仪表板 (`/dashboard`)
- **品牌全景看板**：流光统计指标卡片（已完成、已清理、失败、总计任务）。
- **实时传输监控图表**：ECharts 平滑流光面积图，实时展示上传速率、下载速率与 IO 吞吐峰值。
- **系统与集群负载**：胶囊进度卡展示 CPU、内存、磁盘实时占用，直观呈现各 Bot 节点分流状态。
- **最近动态**：直观展示最近下载完成项与系统运行时环境指标。

### 2. 下载与任务管理中心 (`/downloads`)
- **多标签页切换**：下载记录历史与实时运行队列（正在下载、等待中、已完成、失败）。
- **新建下载任务**：支持添加 HTTP/HTTPS 链接、磁力链接（magnet:?xt=...）及种子文件（.torrent）。
- **任务管理控制**：支持重试、暂停、恢复、单项删除与一键清空历史记录。

### 3. Telegram 频道云盘 (`/drive`)
- **双模浏览视图**：
  - **16:10 网格卡片**：带缩略图封面、微交互悬浮控制栏及类型徽标；
  - **高效列表视图**：展示文件专属彩色图标、大小、日期与快速操作列。
- **缩略图后台预生成与预热**：
  - 顶部流光预热状态指示徽标（如 `封面预热中 45/162 (28%)`），支持一键启动后台静默预热，告别前台浏览漫长排队。
- **自适应视口影院播放弹窗**：
  - 晶莹浅色毛玻璃卡片设计，黄金视口高度约束（彻底解决垂直撑破向下无限延伸的问题）；
  - 支持 **网页大屏展开 / 窗口模式** 一键切换；
  - **无缝切换与连播**：支持“上一集 / 下一集”、键盘快捷键（`←` / `→`）、播放结束自动连播下一视频；
  - **画中画与倍速**：预置 0.5x~2.0x 倍速控制与画中画 (PiP) 模式；
  - **外部播放器联动**：一键唤起 PotPlayer、VLC、IINA 桌面播放器播放绝对直链。
- **直链生态与批量导出**：
  - 单项直链一键复制；
  - 批量导出：支持换行批量复制所选文件直链、一键导出标准 UTF-8 `#EXTM3U` 播放列表文件；
  - **Shift 键区间连选**：按住 Shift 点击实现批量快速连选。

### 4. 机器人集群管理中心 (`/bots`)
- **集群总览与 KPI**：主控与从机状态、免加频道分流就绪数、响应延迟指标与频道公共 Handle 状态；
- **全集群测速与质量报告**：一键并行测量所有 Worker 节点 Ping 与吞吐量，生成评分报告；
- **单连接流播与下载测速**：提供 10MB、100MB、1GB 阶梯样本测速，实时评估首包耗时、码率与卡顿风险；
- **多节点并发分流压测**：5 轮/10 轮/20 轮模拟并发拉取，可视化分流均衡度；
- **节点阵列卡片管理**：单节点测速、用户名复制与安全下线。

### 5. @BotFather 自动铸机与扩容流水线 (`/botfather`)
- **协议号资产池纳管**：统一纳管多个协议号（Session String / `.session` 文件 / `手机号|接码链接`），实时显示持机数（X/20）与健康呼吸灯；
- **多号跨账号接力扩容**：突破单号 20 上限，单号达上限或限流时自动切号接力；
- **单号精准独立铸造**：指定特定协议号进行差额补齐；
- **流水线执行监控终端**：暗色磨砂控制台 (`botfather-pipeline.log`) 实时输出事件高亮日志。
- **协议号资产池（Protocol Account Pool）**：
  - 纳管多个 Telegram API 协议号，支持持有机数进度条（`X/20`）与健康状态追踪；
  - 支持批量导入（多行 `手机号|接码API链接` 文本粘贴或多 `.session` 文件上传）；
- **双模自动化铸造工作台**：
  - **多号接力扩容模式 (Relay Mode)**：突破 Telegram 单号 20 个机器人硬性物理上限（最高可扩容至 200 个），当单号达到 20 个或触发限流时，系统自动无缝切换至下一协议号接力铸造；
  - **单号精准铸造模式 (Single Mode)**：下拉直选指定账号，精确完成存量复用或差额创建（上限 20 个）；
- **运行期零停机热挂载**：无需重启 Docker 容器即可动态添加或卸载 Bot 节点；
- **免加频道分流就绪指示**：从机自动通过公开 Handle 解析 Peer 并激活只读分流；
- **实战测速与基准仪表板**：
  - **单连接播放 vs 多连接并发下载测速**：提供 10MB、100MB、1GB 真实样本测速，对比播放速度与满速下载吞吐；
  - **集群负载压测**：多轮分流均匀度验证与方差评估报告。

### 6. 存储与内存缓存治理中心 (`/cache`)
- **全维度存储监控**：磁盘总容量/已用/可用空间线性渐变仪表、缩略图体积、下载目录占用与内存 LRU 状态。
- **分类治理与安全清理**：
  - **媒体缩略图**：按保留天数清理过期 WebP 或一键清空并重新预热；
  - **下载临时目录**：内置活跃任务绝对保护（绝不误删 Aria2 进行中任务与数据库上传任务）；
  - **Dry-run 试运行分析**：支持预先分析将释放的文件数与空间，不实际删除物理文件；
- **自动清理策略配置**：可视化调整保留小时数、保留天数及清理间隔，即时保存生效。

### 6. 系统设置与运维中心 (`/settings`)
- Segmented 毛玻璃选项卡：客户端连接、Telegram 配置、下载配置、Aria2 配置、直链配置。
- **容器状态面板**：Docker 容器状态、只读自检报告及热重载控制。
- **系统日志终端**：暗色磨砂代码终端窗口，支持文件切换、级别过滤、关键词搜索与实时日志流高亮。

## 技术栈

- **核心框架**：Vue 3 (Composition API `<script setup>`)
- **编程语言**：TypeScript 5.x (严格类型检查)
- **构建工具**：Vite 7.x
- **状态管理**：Pinia 3.x
- **路由管理**：Vue Router 4.x
- **UI 组件库**：Element Plus (定制二次元樱花流光主题与全局组件毛玻璃化)
- **样式方案**：Tailwind CSS + 原生 CSS Variables
- **数据可视化**：ECharts 6.x
- **媒体播放**：Video.js 8.x
- **端到端测试**：Playwright

## 本地开发与脚本

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```
开发服务器将监听 `http://localhost:5173`，所有 `/api` 请求将自动代理至后端 `http://localhost:8080`。

### TypeScript 类型检查
```bash
npm run type-check
```

### 生产打包构建
```bash
npm run build
```
生产文件输出至 `dist/` 目录，已配置高效的代码分包（`vue-vendor`、`ui-vendor`、`utils-vendor`）。

### 自动化端到端测试 (Playwright)
```bash
# 执行全量 Web 管理端测试
npx playwright test

# 查看可视化测试报告
npx playwright show-report
```
