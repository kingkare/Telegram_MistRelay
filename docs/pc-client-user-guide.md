# MistRelay PC 客户端用户指南

本文面向普通用户，说明 MistRelay PC 客户端 P0 版本的登录、浏览、预览和下载流程。

## 1. 登录

1. 启动 PC 客户端。
2. 在登录页填写服务器地址，例如 `http://127.0.0.1:8080`。
3. 点击“测试”，确认服务器可连接。
4. 输入用户名和密码，点击“登录”。

登录成功后会进入“网盘”。客户端会保存服务器地址、访问 token 和 refresh token；访问 token 过期时会自动尝试刷新，刷新失败会回到登录页。

## 2. 网盘浏览

“网盘”页展示 Telegram 频道网盘内容：

- 根目录会显示普通文件和相册。
- 相册来自 Telegram 媒体组，点击相册可进入组内文件。
- 可按文件名搜索，或按类型、时间、大小、名称排序。
- 图片和视频可直接预览，其他文件可从预览层下载。

“最近”页包含两类记录：

- 最近入库：服务器中最新的频道网盘文件。
- 本机最近：本机打开或下载过的文件记录。

## 3. 下载

在预览层点击“下载”会把文件加入下载队列。

下载行为：

- 默认使用“设置”里的下载目录。
- 单文件支持 1 到 8 个 Range 分片线程。
- 全局同时下载任务数支持 1 到 4 个。
- 如果服务器不支持 Range，会自动降级为单线程下载。
- 文件名重复时会自动追加序号，例如 `movie (1).mp4`。

“下载”页可查看：

- 排队、下载中、完成、失败、取消、中断状态。
- 进度、速度、线程数、保存路径。
- 失败和中断任务可重试。
- 完成任务可打开文件或所在文件夹。

## 4. 设置

“设置”页包含普通用户设置：

- 服务器地址。
- 退出登录。
- 默认下载目录。
- 单文件线程数。
- 全局并发数。
- 主题、版本和诊断信息。

主题为 PC 客户端专用浅色二次元风格，登录页和空状态会显示对应插画资产。

## 5. 已知限制

- 当前 P0 主要面向 Windows 桌面包；Linux/macOS 需要自行准备 Tauri 运行依赖。
- 本地目录选择、另存为、打开文件和打开文件夹依赖 Tauri 桌面命令；如果命令未在目标平台实现，会显示失败提示。
- 暂停和断点续传不在 P0 范围内；异常退出后的未完成任务会标记为“已中断，可重试”。
- 系统通知使用 Web Notification 能力，是否弹出取决于系统和 WebView 权限。
- 服务端权限模型仍以现有后端鉴权为准；PC 客户端隐藏后台管理入口，但不能替代服务端权限控制。
