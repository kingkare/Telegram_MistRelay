# MistRelay PC 插画素材规范

版本：`v2 / 2026-07-15`

本文件记录 PC 客户端 v2 已交付 SVG 的现状、用途与验收规则。实现层的布局与交互以 [MistRelay PC 客户端 UI 实现规范](mistrelay-pc-ui-spec.md) 为准。

## 1. 当前资产

| 文件 | 画布 | 目标位置 | 语义 |
| --- | --- | --- | --- |
| `illustrations/login-hero.svg` | `1280 x 720`，`16:9` | 登录表单左侧 | 安全连接远程文件空间 |
| `illustrations/empty-drive.svg` | `640 x 480`，`4:3` | 空网盘、空相册、最近为空 | 存储架暂时为空，系统可用 |
| `illustrations/connection-error.svg` | `640 x 480`，`4:3` | 连接失败状态 | 两端中继链路断开，可重试 |
| `illustrations/download-idle.svg` | `640 x 480`，`4:3` | 下载队列为空 | 文件已归档，当前工作区空闲 |

所有插画位于 `web/src/assets/pc-theme/illustrations/`。品牌标记单独位于 `web/src/assets/pc-theme/app-mark.svg`，它复用桌面应用图标构图，供侧栏和登录品牌区使用。

`web/src/assets/pc-theme/anime/*.webp` 和 `anime/source/*` 为兼容/历史素材。本轮不删除它们，但 v2 页面不应新增对旧 WebP 的引用。

## 2. 统一美术规则

- 白色和冷灰占主体，靛蓝 `#4F5FD7` 附近颜色表达连接和主结构，紫色只作少量层次。
- 状态图以储物架、中继设备、归档托盘等对象为主体，不使用幼态人物、吉祥物或现有动漫 IP。
- 插画中不出现可读文字、按钮、表单、进度条、窗口、鼠标指针或完整软件界面，避免伪造可交互 UI。
- 不使用装饰圆球、散景、霓虹、彩带、烟花、大面积紫色或高频电路线。
- 错误图只允许局部危险红；下载空闲图不使用巨大绿色勾、下载箭头或庆祝语义。
- 阴影柔和，边框清楚，缩小到 `260-320px` 宽时仍能辨认核心对象和状态。

## 3. 单图规格

### 3.1 登录图

`login-hero.svg` 沿用经过确认的成熟轻科技构图：成年系统工程师位于中右区域，抽象文件对象经中继节点形成连接。页面必须保持原生比例完整显示，不得用 `cover` 裁掉人物、文件对象或中继节点。

### 3.2 空内容

`empty-drive.svg` 使用双层空储物架和极淡占位轮廓表达“暂时没有内容”。它同时服务根目录、相册和最近记录，不能加入搜索、上传、删除或故障专属符号。

### 3.3 连接失败

`connection-error.svg` 使用左右两个中继终端和中央断开的靛蓝链路。唯一错误强调是断点附近的小型红色状态块；不使用满屏红、巨大警告三角、Wi-Fi 图标、错误代码或设备损坏效果。

### 3.4 下载空闲

`download-idle.svg` 使用已落入归档托盘的无字文件片表达“任务已整理、队列空闲”。小型靛蓝完成线只作辅助，不使用绿色主色、进度条、速度数字或下载箭头。

## 4. 集成规则

- SVG 使用项目内静态 import，不依赖远程字体、图片、脚本或外部 URL。
- 状态图容器按 `4:3` 预留稳定尺寸；登录图按 `16:9` 预留并使用 `contain`。
- 图片装载失败时仍保留容器尺寸和状态文案，不能造成页面跳动。
- 状态文案和重试/清除筛选操作由 Vue 组件渲染，不写入 SVG。
- SVG 保持可由标准 XML 解析器直接解析，颜色和滤镜只使用浏览器内建能力。

## 5. 验收清单

- [ ] 五个 v2 SVG 均可被标准 XML 解析器读取，且无外部资源引用。
- [ ] 登录图为 `1280 x 720`；三张状态图均为 `640 x 480`。
- [ ] 在白色和 `#F6F8FC` 背景上主体边界清楚，没有大面积单一紫色。
- [ ] 连接失败在约 `280px` 宽时仍能看出链路断点，错误红保持局部。
- [ ] 空内容和下载空闲在约 `260px`、`320px` 宽时不与下方文案争抢层级。
- [ ] 画面无可读文字、伪 UI、装饰圆球、幼态人物、第三方标志或巨大绿色勾。
- [ ] `1100 x 720`、`1366 x 768`、`1920 x 1080` 下均无关键对象裁切或布局跳动。
