# MistRelay PC 原创二次元插画生产规格

## 1. 目标与范围

本规格只覆盖 PC 客户端的四张装饰性状态插画，不定义新功能，也不在插画中伪造可交互控件。

视觉目标：轻量、成熟、克制的二次元科技感，以高级桌面软件的清晰度为主，角色和场景作为点缀。画面采用白色基底、蓝紫渐变和柔和光影，适合放入 Figma 级高保真产品原型及真实软件界面。

功能边界：画面不得暗示 P0 不具备的上传、分享、同步、暂停续传、自动更新或后台管理能力；不得出现 Telegram、Windows 或任何现有产品的标志、界面和角色形象。

## 3. 统一美术圣经

### 3.1 固定角色

四张图使用同一位原创角色“米拉”，并以首张通过验收的 `login-hero` 角色裁切图作为后续三张图的身份参考。

- 明确为 25 岁左右的成年女性系统工程师；成熟、冷静、亲和，不使用幼态脸型或儿童比例。
- 身高比例约 7-7.5 头身，肩颈和四肢比例自然，动作轻巧但不夸张。
- 深海军蓝齐下巴短发，右侧一缕低饱和紫色挑染；灰紫色眼睛；细直眉；五官简洁而有辨识度。
- 白色无领短款科技夹克，钴蓝结构线，内搭浅灰高领上衣，石墨灰直筒长裤，白灰低帮鞋；无品牌、无文字。
- 唯一配件为左腕半透明蓝紫色终端；不加猫耳、发箍、徽章、领带、武器或夸张饰品。
- 四图保持脸型、发型、挑染位置、眼睛颜色、服装裁片和腕端位置一致，不随场景换装或改变年龄。

固定角色不能仅依赖同一随机种子来保持一致。生产时必须同时使用已确认的角色参考图，并优先保证身份和服装一致，再调整姿态和场景。

### 3.2 造型与光影

- 精致日系动画造型，干净线稿、克制的赛璐璐分层，加少量柔和 2.5D 体积光；不是厚涂海报，也不是扁平儿童矢量插画。
- 轮廓清楚，面部和手部准确，细节在缩至 `260px` 宽时仍可辨认。
- 白色或接近白色背景占画面至少 60%；用大面积低对比的半透明平面、细线和雾状光带构成科技层次。
- 不使用霓虹赛博朋克、黑色背景、发光城市、密集电路线、装饰性光球、彩带或高频纹理。
- 光源固定为左上方柔和日光，右下方仅有很浅的冷灰蓝投影；阴影边缘柔软，不做高反差戏剧光。
- 画面内不出现可读文字、数字、表单、按钮、光标或完整软件窗口。抽象文件卡片必须是无字的几何面片，避免被误认为可操作 UI。

### 3.3 色彩配额

| 用途 | 色值 | 画面占比建议 |
| --- | --- | --- |
| 纸白背景 | `#FFFFFF` / `#F8FAFF` | 60-72% |
| 主蓝 | `#496FEA` | 8-14% |
| 主紫 | `#7864DF` | 6-12% |
| 淡蓝紫 | `#CAD5FF` / `#E7E9FF` | 10-18% |
| 石墨中性 | `#29334A` / `#66708A` | 5-10% |
| 冷青点缀 | `#65C7CF` | 不超过 4% |
| 错误玫红，仅连接失败图 | `#E68A9D` | 不超过 5% |

蓝紫只用于品牌层次和光带，不能把整张图染成单一紫色。肤色、白色、石墨灰和少量冷青用于拉开层次。

## 5. 单图生产规格

### 5.1 `login-hero.webp`

**画布与构图**

- 母版 `2560 x 1440`，交付 `1280 x 720`，严格 `16:9`。
- 米拉位于画面中右区域，身体约占画面高度 68%，三分之四侧身朝右，视线自然朝向画面外的登录表单方向。
- 左侧放置三块无字半透明文件片，经一条细而连续的蓝紫光带连接至中部的抽象安全中继节点；右侧仅保留轻量终点光迹，不画具体产品标志。
- 角色面部建议位于 `x=57-68%`、`y=20-36%`；角色和中继节点均在中央安全区内。
- 外圈安全区为左右各 `10%`、上下各 `8%`；该区域只能放纯背景和可被裁切的淡光带。
- 不需要为画内文案留位置，因为实际登录表单位于插画容器外部。

## 7. 成图验收清单

### 7.1 主题与角色

- [ ] 第一眼是成熟桌面软件产品插画，而不是儿童应用、游戏立绘或营销海报。

- [ ] 四图角色明确成年，脸型、发型、紫色挑染、眼睛、服装裁片和左腕终端一致。

## 8. 生产留档

为证明原创性并方便后续重制，每张最终图应留存：生成工具与模型版本、完整正负提示词、生成日期、随机种子（如有）、角色参考图哈希、人工修改说明和最终文件哈希。角色参考只能使用本项目先行生成并确认的米拉角色图，不得使用现有动漫、游戏或商业插画作为参考。

集成提醒：当前 `pc-theme.css` 的纯 CSS 降级色仍以青绿和珊瑚色为主。若客户端整体主题切换为本规格的蓝紫白方案，代码负责人需要同步降级渐变；本素材规格不直接修改客户端样式。
