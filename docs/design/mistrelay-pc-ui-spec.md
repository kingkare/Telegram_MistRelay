# MistRelay PC 客户端 UI 实现规范

版本：`v2 / 2026-07-15`

状态：**唯一实现规范（canonical）**

本文定义 Tauri 桌面客户端 `/pc/*` 的视觉、布局、交互与验收规则。其他设计稿、截图提示词或历史文档与本文冲突时，一律以本文为准。

## 1. 目标与边界

MistRelay PC 首先是高效率的桌面网盘工具，其次才有轻量科技感。界面应成熟、克制、适合反复浏览文件和管理下载任务，不采用营销落地页、玻璃拟态或后台管理仪表盘的构图。

保留现有后端接口和本地数据格式，主流程固定为：

```text
登录 -> 浏览或搜索 -> 打开预览 -> 下载或另存为
```

本轮不增加上传、分享、批量操作、暂停续传、暗色主题、自动更新或管理后台能力。

## 2. 全局框架

### 2.1 窗口与壳层

| 项目 | 固定值 | 行为 |
| --- | ---: | --- |
| 最小窗口 | `1100 x 720` | 全部主操作可达，不出现横向滚动 |
| 设计基准 | `1366 x 768` | 视觉回归主画板 |
| 大屏验收 | `1920 x 1080` | 增加内容密度，不放大字号 |
| 侧栏 | `184px` | 三个验收宽度均不折叠 |
| 顶栏 | `56px` | 固定在内容区顶部 |
| 内容内边距 | `18px` | 四边一致 |
| 内容滚动 | `.pc-content` | 侧栏和顶栏不随内容滚动 |

Tauri 继续使用系统原生窗口边框，不在 WebView 中绘制最小化、最大化或关闭按钮。所有 grid/flex 子项设置可收缩的最小宽度，长文本必须省略或换行，不能挤出容器。

### 2.2 侧栏

- 顶部使用 `app-mark.svg` 与 `MistRelay` 品牌名；不增加宣传语或版本徽章。
- 导航固定为“网盘、最近、下载、设置”，图标来自现有 Element Plus 图标库。
- 导航项高 `40px`、圆角 `8px`。选中态使用浅靛蓝背景和深靛蓝文字；hover 只改变颜色，不位移。
- 底部使用紧凑账号/服务器入口，不再重复展示大卡片或假在线状态。

### 2.3 顶栏与内容区

- 顶栏左侧只显示一次当前页面标题；不重复品牌、服务器域名或固定绿色在线点。
- 背景以白色、冷灰为主，区块通过留白和 `1px` 分隔线组织；页面分区不包装成悬浮卡片。
- 进入任意 PC 路由时给 `body` 添加 `pc-mode`，离开时移除。Element Plus 的 Dialog、Dropdown、Select 和 Message 等 Teleport 内容必须依赖该类继承 PC 主题。

## 3. 视觉系统

### 3.1 颜色与形态

| Token | 值 | 用途 |
| --- | --- | --- |
| `--pc-color-bg` | `#F6F8FC` | 内容背景 |
| `--pc-color-surface` | `#FFFFFF` | 表面、输入和弹层 |
| `--pc-color-surface-soft` | `#F0F3FA` | hover 与空白封面 |
| `--pc-color-border` | `#E1E6F0` | 边框和分隔线 |
| `--pc-color-text` | `#202637` | 标题和正文 |
| `--pc-color-text-muted` | `#697386` | 元信息 |
| `--pc-color-primary` | `#4F5FD7` | 主操作与选中态 |
| `--pc-color-primary-strong` | `#3D4AB5` | hover/pressed |
| `--pc-color-primary-soft` | `#EEF0FF` | 活动背景 |
| `--pc-color-accent` | `#7B55D9` | 品牌和插画局部，禁止大面积使用 |
| `--pc-color-success` | `#23845B` | 完成状态 |
| `--pc-color-warning` | `#A86B0E` | 警告状态 |
| `--pc-color-danger` | `#C53F56` | 删除和错误 |

主按钮使用纯色，品牌渐变只用于品牌标记和插画局部。卡片、控件和弹层圆角限制为 `6-8px`；禁止装饰光球、发光边缘、大面积紫色背景和旧玻璃态动画。

### 3.2 字体、图标与状态

```css
font-family: "Segoe UI Variable", "Segoe UI", "PingFang SC",
  "Microsoft YaHei", sans-serif;
letter-spacing: 0;
```

正文采用 `14/20px`，辅助信息采用 `12/16px`，顶栏标题采用 `18/24px`。字重只使用 `400/500/600/700`。熟悉的刷新、下载、删除、返回、网格和列表操作使用图标按钮；不熟悉的图标必须提供 Tooltip，所有图标按钮提供 `aria-label`。

## 4. 登录

- 登录页不显示登录后的侧栏和顶栏，采用无嵌套卡片的双栏布局；右侧为紧凑登录表单。
- 左侧使用 `illustrations/login-hero.svg`，保持原生 `16:9` 比例和完整构图，使用 `contain` 或等价规则，不裁切人物和中继对象。
- 服务器地址变化时立即清除旧连接测试结果，避免结果与当前地址错配。
- 用户点击登录时，只有当前地址尚未验证才先测试连接；已验证的同一地址直接执行登录。
- 表单加载、校验失败、连接失败和登录失败保持固定布局，不因状态文案改变按钮或输入框尺寸。

## 5. 网盘

### 5.1 工具区

网盘采用两层工具区：第一行为返回/面包屑、网格/列表切换和刷新；第二行为搜索、类型筛选、排序和提交。相册只允许一层，返回始终回到根目录。筛选或排序变化回到第 1 页，刷新保留当前上下文。

默认使用紧凑网格，之后沿用用户已保存的网格/列表偏好。清除搜索和类型筛选应合并为一次状态重置与一次请求，不能重复加载。

### 5.2 网格与列表

文件和相册封面统一为 `16:10`，缩略图使用 `object-fit: cover`；加载骨架和 fallback 保持相同比例，避免布局跳动。

网格在三个验收宽度使用确定列数：

| 窗口宽度 | 内容安全区宽度 | 列数 | 间距 |
| ---: | ---: | ---: | ---: |
| `1100px` | `880px` | `5` | `14px` |
| `1366px` | `1146px` | `6` | `14px` |
| `1920px` | `1700px` | `8` | `14px` |

推荐实现为默认 `5` 列，在 `1280px` 起切为 `6` 列，在 `1680px` 起切为 `8` 列；列使用 `minmax(0, 1fr)`，不得依赖 `auto-fill` 产生第 7 或第 9 列。

卡片信息区固定容纳文件名和一行元信息，文件名单行省略并提供完整 Tooltip。删除按钮只在 `hover`、`focus-within` 或无 hover 能力的设备上显示。列表采用固定列轨道，名称列可收缩，长文件名不得改变操作列位置。

**下载只能从预览层发起。** 网格卡片、相册卡片和列表行均不放直接下载按钮；文件主体打开预览，相册主体进入相册，允许删除的来源保留删除操作。

### 5.3 状态与分页

统一状态面板至少支持加载、连接失败、根目录为空、相册为空和筛选无结果：

- 连接失败使用 `illustrations/connection-error.svg` 并提供“重试”。
- 根目录或相册为空使用 `illustrations/empty-drive.svg`，文案按上下文区分。
- 筛选无结果不伪装成空网盘，提供“清除筛选”，执行一次状态重置和一次请求。
- 加载保留内容骨架尺寸；上一批数据不得与新的错误态混杂。
- 翻页后只将 `.pc-content` 滚回网格/列表起点，不移动固定壳层。

## 6. 最近

最近页使用“最近入库 / 本机最近”两个标签页，禁止并排堆叠两个大区块。

- “最近入库”使用与网盘一致的紧凑媒体网格。
- “本机最近”使用带操作类型、文件名和时间的紧凑列表。
- 相册点击后直接进入网盘对应相册；无法定位时显示明确错误，不停留在假详情页。
- 最近页打开的预览传入 `allowDelete=false`，不显示不可执行的删除动作。
- 两个标签各自处理加载、失败和空状态，切换标签不清除另一标签已经获取的数据。

## 7. 下载

下载页删除重复页标题、四张统计卡和常驻“继续队列”操作。状态计数合并为紧凑标签栏，任务使用一个带分隔线的列表，不在任务项外继续嵌套卡片。

每行固定展示文件名、目标位置、状态/进度、速度或完成时间，以及当前状态允许的图标操作。图标按钮尺寸固定并提供 Tooltip，动态状态文字不得导致行高或列宽变化。

“清理”只移除已完成任务；失败、取消和中断记录保留，供用户重试或排查。空队列使用 `illustrations/download-idle.svg`。不伪造暂停、断点续传、剩余时间或拖拽排序。

## 8. 设置与服务器切换

设置页使用左侧分类导航和右侧单一内容面板，分类固定为：

1. 连接与账户
2. 下载
3. 客户端

下载目录、并发数等可编辑项先写入页面草稿，用户点击“保存”后一次提交；离开未保存页面时沿用现有产品行为，不引入自动保存。客户端版本和诊断信息放在“客户端”的折叠高级区。

更换服务器按固定顺序执行：校验新地址 -> 测试连接 -> 请求用户确认 -> 清除旧服务器登录态 -> 跳转登录页。确认前不修改当前会话，确认后不得把旧 Token 发送到新服务器。

## 9. 预览与公共接口

媒体预览统一使用深色工具栏，展示文件标题、前后导航以及下载/另存为操作；按钮尺寸、Tooltip 和键盘焦点规则与 PC 主题一致。

公共接口变更：

- `MediaPreview` 新增 `allowDelete?: boolean`，默认值为 `true`。网盘传 `true`，最近页传 `false`。
- 统一状态面板接收状态类型、标题、插画和可选操作；页面负责提供上下文文案与操作回调。
- `pcDrive` Store 提供一次请求完成的 `resetFilters()`，同时清除搜索、类型和分页状态。

不新增后端 API、数据库字段或新的本地存储格式。

## 10. 素材

实现只引用下列 v2 SVG：

- `web/src/assets/pc-theme/app-mark.svg`
- `web/src/assets/pc-theme/illustrations/login-hero.svg`
- `web/src/assets/pc-theme/illustrations/empty-drive.svg`
- `web/src/assets/pc-theme/illustrations/connection-error.svg`
- `web/src/assets/pc-theme/illustrations/download-idle.svg`

`anime/*.webp` 与 `anime/source/*` 是兼容/历史素材，不是 v2 新实现的引用源。SVG 的具体语义、比例和验收要求见 [PC 插画素材规范](mistrelay-anime-assets.md)。

## 11. 测试与验收

- 使用稳定的 `data-testid` 覆盖登录、网盘网格/列表、相册、筛选无结果、错误重试、最近页跳转、预览权限、下载筛选和设置保存。
- Playwright 运行产物必须写到 Vite 监听目录之外并加入忽略规则，避免测试截图或报告触发页面重载。
- 在 `1100 x 720`、`1366 x 768`、`1920 x 1080` 截取完整壳层视觉基线；列数必须分别为 `5/6/8`。
- 三个画板均不得出现横向溢出、控件重叠、长文件名撑破布局、Teleport 弹层主题错位或图片裁切错误。
- 验证下载只可从预览层发起；最近页预览无删除；清理下载只移除完成项；服务器切换不复用旧 Token。
- 运行 `npm run type-check`、`npm run build` 和完整 Playwright 套件；发布构建额外检查 Windows 100%/125% DPI。

## 12. 固定默认值

- Tauri 最小窗口继续为 `1100 x 720`，不改默认窗口配置。
- 网盘首次默认紧凑网格，之后读取用户已有视图偏好。
- 下载记录继续作为设备级本地记录；最近记录继续按服务器隔离。
- 本规范不要求迁移或删除旧 WebP 素材。
