# MistRelay PC 网盘主界面高保真设计规范

版本：P0 / 2026-07-10
目标画板：`1366 x 768`
适配画板：`1100 x 720`、`1920 x 1080`
实现基线：Tauri 2 + Vue 3 + Element Plus

## 1. 设计目标与边界

主界面首先是高效率的 Windows 桌面网盘，其次才是带轻量二次元气质的视觉产品。整体应像可直接使用的成熟桌面软件，而不是宣传落地页、概念海报或被装进展示卡片的网页 mockup。

视觉关键词：

- 白色和冷中性灰为主，蓝色负责交互，紫色只做渐变端点和轻量强调。
- 信息密度接近文件管理器，控件紧凑、对齐稳定、滚动区域明确。
- 柔和光影、精细边框、少量半透明层；不使用霓虹、发光大标题、装饰光球和大面积紫色背景。
- 二次元素材为原创、成年感、轻科技感的状态插画，不使用幼态比例、夸张表情、现有动漫 IP 或抢占内容区的大角色。
- 正常有文件的根目录不放大幅角色插画。动漫感通过配色、封面 fallback、空状态和细节动效表达。

P0 根目录允许出现的能力：浏览、搜索、类型筛选、排序、网格/列表切换、刷新、分页、进入相册、预览、下载/另存为、单项删除。

明确禁止：上传、分享、批量选择、批量删除、一键清空、暂停/续传、自动更新入口，以及 Telegram、OpenAI、aria2、Docker、API 密钥等管理后台入口。

## 4. 字体、图标与间距

字体栈：

```css
font-family: "Segoe UI Variable", "Segoe UI", "PingFang SC",
  "Microsoft YaHei", sans-serif;
letter-spacing: 0;
```

不依赖远程字体。若后续随安装包内置 Inter，只用于拉丁字符和数字，不改变中文 fallback。

| 层级 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Page title | `18/24px` | `700` | 顶栏“网盘” |
| Path title | `16/22px` | `700` | 面包屑当前层 |
| Body strong | `14/20px` | `600` | 文件名、导航文字 |
| Body | `14/20px` | `400` | 按钮、输入、列表内容 |
| Meta | `12/16px` | `400` | 文件大小、类型、时间 |
| Status | `12/16px` | `600` | 相册和任务状态标签 |

间距基于 `4px` 单位，常用值为 `4 / 8 / 10 / 12 / 14 / 16 / 18 / 24 / 32`。已有布局中的 `10px` 控件间距、`14px` 网格间距和 `18px` 页面内边距保留，避免无必要的结构改造。

图标使用项目已安装的 `@element-plus/icons-vue`，线宽和视觉重量保持一致：

- 侧栏图标 `18px`，品牌标记 `18px`。
- 输入前缀、按钮图标 `16px`。
- 文件类型图标 `36px`（网格 fallback）或 `18px`（列表）。
- 熟悉的刷新、下载、删除、网格、列表可使用纯图标按钮，但必须提供 `title`/tooltip 和 `aria-label`。

## 5. 主框架

### 5.1 侧栏

- 宽 `184px`，背景 `--pc-color-sidebar`，右边 `1px --pc-color-border`。
- 内边距 `16px 12px`；品牌区高 `40px`，下方 `12px` 内边距和一条分隔线。
- 品牌标记 `28 x 28px`、圆角 `8px`、品牌渐变；白色字母 `M`，不添加发光。
- 品牌名 `MistRelay`：`15/20px`、`700`。
- 导航距品牌分隔线 `8px`。顺序固定：网盘、最近、下载、设置。
- 导航项 `160 x 40px`，水平内边距 `12px`，图标与文字间距 `10px`，圆角 `8px`。
- 活动项背景 `--pc-color-primary-soft`，文字/图标 `--pc-color-primary-strong`，左侧不再叠加彩条。
- hover 只改变背景和文字色，不位移；pressed 背景为 `#E2E6FF`。
- 侧栏底部留白，不放升级、推广、后台管理或大幅角色图。

### 5.2 顶栏

- 高 `56px`，左右内边距 `18px`，底边 `1px --pc-color-border`。
- 背景 `rgba(255,255,255,.90)`；仅在系统支持时使用 `backdrop-filter: blur(12px)`。
- 左侧只显示当前页标题“网盘”。不重复品牌，不加入搜索框、头像或未实现的账号菜单。
- 标题左边缘为 `202px`（全画板坐标），垂直居中。

### 5.3 内容区

- 背景 `--pc-color-bg`，内边距 `18px`。
- `.pc-drive-view` 采用单列 grid，区块间距固定 `16px`。
- 页面宽度不设置 `max-width`，大屏仍用于展示更多文件列。
- 只有 `.pc-content` 纵向滚动。搜索行、网格卡片、分页不得产生横向滚动。

## 6. 根目录工具区

### 6.1 路径与视图操作行

高度 `40px`，从左到右：

1. 根目录面包屑，占满剩余宽度。根目录只显示可点击的“网盘”。
2. 网格/列表分段控件，整体 `76 x 36px`，两个 `36 x 32px` 图标选项，中间 `4px` 间隙；选中项背景白、主色图标、`1px` 边框和 `--pc-shadow-sm`。
3. 刷新图标按钮 `36 x 36px`，与分段控件间距 `10px`。

进入相册时，最左侧增加 `36 x 36px` 返回图标按钮，随后显示 `网盘 / 相册名`。当前相册名单行省略，完整名称用 tooltip 显示。相册不允许二级嵌套，因此返回始终回到根目录。

### 6.2 搜索筛选行

高度 `36px`，列定义保持与现有 `drive.vue` 对齐：

```css
grid-template-columns: minmax(220px, 1fr) 128px 160px 76px;
gap: 10px;
```

| 控件 | 尺寸 | 文案/内容 |
| --- | --- | --- |
| 搜索输入 | `min 220px x 36px` | 前缀 Search 图标；placeholder“搜索文件名或描述” |
| 类型筛选 | `128 x 36px` | 全部、视频、图片、音频、文档 |
| 排序 | `160 x 36px` | 时间/大小/名称与升降序组合 |
| 搜索按钮 | `76 x 36px` | Search 图标 + “搜索” |

搜索按 Enter 或点击按钮提交；清空输入后立即刷新。筛选和排序变化后自动回到第 1 页。刷新保留当前搜索、筛选、排序和相册上下文。

控件外观：白底、`1px --pc-color-border`、圆角 `8px`、正文 `14px`。默认不使用阴影。

## 7. 网格视图

网格使用当前可直接落地的规则：

```css
grid-template-columns: repeat(auto-fill, minmax(164px, 1fr));
gap: 14px;
```

| 画板 | 内容安全区宽 | 列数 | 单卡宽度 | 典型首屏 |
| --- | ---: | ---: | ---: | --- |
| `1100 x 720` | `880px` | `5` | `164.8px` | 2 行完整 + 后续滚动 |
| `1366 x 768` | `1146px` | `6` | `179.3px` | 2 行完整 + 后续滚动 |
| `1920 x 1080` | `1700px` | `9` | `176.4px` | 4 行附近，取决于分页栏 |

单卡结构：

- 外层圆角 `8px`、白底、`1px --pc-color-border`、`--pc-shadow-sm`，overflow hidden。
- 封面严格 `4:3`，`object-fit: cover`；缩略图不得被拉伸。
- 信息区最小高 `56px`，内边距 `9px 10px 10px`。
- 文件名单行省略，`14/19px`、`600`；完整名称通过原生 title 或 tooltip 查看。
- 元信息距标题 `3px`，`12/16px`。文件显示大小；相册显示“n 个文件 · 总大小”。
- 相册标记位于封面左下或右下，`12/16px`、高 `22px`、圆角 `4px`；避免胶囊形。
- 无缩略图时使用 `--pc-gradient-cover` 叠加 `--pc-color-surface-soft`，中心显示对应文件类型图标。
- 视频封面可在左下显示时长，但只有后端提供可靠时长时才出现；P0 不伪造数据。

卡片交互：

- 默认：`--pc-shadow-sm`。
- hover：边框 `#C9D0E4`、`--pc-shadow-md`、向上移动 `1px`；持续 `160ms`。
- pressed：不位移，背景 `#FAFBFF`。
- keyboard focus：外侧 `3px --pc-color-focus`，不能只靠阴影。
- loading：封面骨架保持 `4:3`，信息区同时保留两条骨架，防止加载后跳动。
- 封面加载失败：立即切换文件类型 fallback，不显示破图图标。

快捷操作：

- 文件卡封面右上为 `30 x 30px` 下载和删除图标按钮，间距 `6px`；默认仅在 hover、focus-within 时显示。
- 相册卡只显示删除；点击卡片主体进入相册。
- 图标按钮底色 `--pc-color-cover-overlay`、白色图标；删除 hover 使用 `--pc-color-danger`。
- 对不支持 hover 的环境，快捷操作保持可见。
- 单击文件卡主体打开预览。下载按钮直接使用默认目录；另存为位于预览层，不在卡片上增加第三个按钮。

## 8. 列表视图

列表为一个真实的数据表式容器，不在外层再套卡片。白底、`1px` 边框、`8px` 圆角，表头可在内容滚动时保持在列表顶部。

列定义：

```css
grid-template-columns: minmax(220px, 1fr) 96px 128px 156px 76px;
column-gap: 12px;
```

| 列 | 内容 | 对齐 |
| --- | --- | --- |
| 名称 | `30px` 类型图标 + 文件名 | 左 |
| 类型 | 相册/视频/图片/音频/文件 | 左 |
| 大小 | 文件大小；相册“n 个 · 总大小” | 左，数字等宽特性可用 |
| 修改时间 | 本地化日期时间 | 左 |
| 操作 | 下载、删除图标 | 右 |

- 表头高 `38px`，背景 `#F8F9FD`，`12/16px`、`600`、次级文字色。
- 数据行高 `48px`，水平内边距 `12px`，行间 `1px` 分隔线。
- 行 hover 背景 `#F5F7FC`；focus-within 使用内嵌 `2px` 主色焦点线。
- 名称必须 `min-width: 0` 并单行省略，其他列不得被长文件名挤出。
- 文件行操作显示下载与删除；相册行操作只显示删除。图标按钮 `30 x 30px`。
- 在 `1100px` 验收宽度仍保留全部五列。只有低于项目验收范围时才可隐藏类型或时间列。

## 9. 分页

- 仅当 `total > pageSize` 时出现。
- 距最后一行/网格 `16px`，靠右，最小高 `36px`。
- 布局固定为 `total, sizes, prev, pager, next`，页容量为 `20 / 40 / 80 / 120`，默认 `40`。
- 当前页使用主色实底或主色描边，避免蓝紫渐变铺满全部页码。
- 页码变化后内容滚动回网格/列表起点，但不把整个窗口滚到顶部导航之外。

## 10. 状态规范

### 10.1 Loading

- 初次加载显示 12 个与真实卡片同尺寸的骨架，6 列基准画板为 2 行。
- shimmer 从左到右，周期 `1.4s`，只改变背景位置，不改变透明度和尺寸。
- `prefers-reduced-motion: reduce` 时关闭 shimmer，保留静态骨架。
- 手动刷新已有数据时保留旧布局并让刷新按钮旋转，避免整页闪空；若实现成本受限，可沿用骨架，但必须保持网格尺寸。

### 10.2 Empty

- 空状态为内容区内的单一状态面，不与空卡片嵌套。
- 最小高 `360px`，中心对齐；插画显示尺寸 `288 x 216px`，源文件 `640 x 480 WebP`。
- 根目录文案“暂无文件”；相册内文案“此相册暂无文件”。不显示上传 CTA，因为 P0 无上传功能。
- 插画：原创成年角色在轻量透明数据屏旁整理文件，白底、蓝紫衣饰、柔和灰蓝阴影；人物不超过插画面积 38%，表情克制。
- 图片缺失时使用 CSS 渐变面、文件图标和相同占位尺寸，不能引起布局坍塌。

### 10.3 Error

- 查询错误在工具栏下方显示左对齐 alert，最大宽 `720px`，保留明确错误文本和 error icon。
- 错误不得覆盖搜索工具栏。重试使用现有刷新按钮，不增加大幅营销式错误页。
- 连接完全不可用且无内容可显示时，可使用 `connection-error.webp`，视觉规则与空状态一致。

### 10.4 删除确认

- 删除必须进入 Element Plus modal，不能用 toast 代替确认。
- 对话框宽 `420px`，圆角 `8px`，标题“删除确认”，正文明确文件或相册名称。
- 主操作“删除”为危险色实底，次操作“取消”为中性按钮；默认焦点在取消。
- 不出现“同时删除全部”“不再提醒”等扩展选项。

## 11. 控件状态

| 状态 | 输入/选择器 | 中性按钮 | 主按钮 | 图标按钮 |
| --- | --- | --- | --- | --- |
| Default | 白底、灰边 | 白底、灰边 | `#4F5FD7`、白字 | 透明或白底 |
| Hover | 边 `#AEB8CE` | 主色边、浅主色底 | `#3D4AB5` | `#EEF0FF` |
| Pressed | 边 `#8794B0` | `#E2E6FF` | `#343F9B` | `#E2E6FF` |
| Focus | 外侧 `3px` focus ring | 同左 | 同左 | 同左 |
| Disabled | `opacity: .48`、无阴影 | 同左 | 同左 | 同左 |

- `901px` 及以上：保持侧栏布局。
- `821px - 900px`：若浏览器调试触达，侧栏可转顶部横向导航，搜索行仍尽量四列。
- `820px` 及以下：沿用现有两列搜索工具栏 fallback；这不是 P0 桌面验收尺寸。
- 任意宽度不得按 viewport 动态缩放字体。长文件名、相册名和错误信息使用省略或换行解决。

## 14. Figma 交付规则

Frame 命名：

- `PC / Drive / Root / Grid / 1366x768`
- `PC / Drive / Root / List / 1366x768`
- `PC / Drive / Album / Grid / 1366x768`
- `PC / Drive / Root / Empty / 1366x768`
- `PC / Drive / Root / Loading / 1366x768`
- `PC / Drive / Root / Error / 1366x768`
- 对应创建 `1100x720` 和 `1920x1080` 响应式验收 Frame。

组件至少包含以下 variants：

- `NavItem`: default / hover / active / focus / disabled。
- `Button`: neutral / primary / danger / icon，及 default / hover / pressed / focus / loading / disabled。
- `Field`: default / hover / focus / filled / error / disabled。
- `MediaCard`: image / video / document / audio / album / fallback，及 default / hover / focus / loading。
- `ListRow`: file / album，及 default / hover / focus。
- `StatePanel`: empty / connection-error。

原型展示要求：

- 导出图就是软件 WebView 客户区，不显示 Figma 编辑器、画布注释、设备外框或悬浮展示卡。
- 使用真实比例的中文文件名、文件大小和时间，禁止 lorem ipsum。
- 缩略图应清晰呈现真实文件类别；不要用模糊风景图填满所有卡片。
- 1x PNG 截图必须为 `1366 x 768`；开发标注另附，不叠在最终高保真截图上。

## 16. 验收清单

- `1366 x 768` 根目录为 6 列网格，工具栏单行、文件名不溢出、分页可达。
- `1100 x 720` 为 5 列网格，四个查询控件仍同一行，无水平滚动。
- `1920 x 1080` 为 9 列网格，字体和控件不随窗口放大。
- 侧栏仅四个普通用户入口，无深色管理后台视觉。
- 白/中性灰占主体，蓝紫渐变只用于品牌和少量插画细节。
- 正常根目录没有大幅角色图；空状态插画原创、成年感、不幼稚。
- 网格和列表都可打开、下载并删除单项；删除均有二次确认。
- hover、focus、loading、empty、error、disabled 状态齐全且不改变布局尺寸。
- 图片加载失败时显示稳定 fallback；骨架和真实卡片尺寸一致。
- 不出现上传、分享、批量操作、暂停续传、自动更新或后台设置入口。
